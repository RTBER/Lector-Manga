# Lector Manga

[**Abrir el lector**](https://rtber.github.io/Lector-Manga/)

Lector de ZIP, CBZ e imágenes para navegadores modernos de PC, iPad y móvil. Versión web del lector entregado para Windows.

## Uso

Abre el enlace y pulsa **Abrir archivo**. Elige el ZIP/CBZ o las imágenes desde tu dispositivo. En iPad, puedes añadir el sitio a la pantalla de inicio desde Compartir en Safari.

Las páginas se ordenan por nombre. Incluye lectura de derecha a izquierda o al revés, zoom y navegación por página. La selección de carpetas y pantalla completa dependen del navegador.

## Privacidad y límites

Las imágenes se leen y descomprimen en el navegador. La aplicación no las sube, no usa API y no incorpora analítica. GitHub recibe las peticiones normales al cargar el sitio. No se publican mangas ni datos de usuario en este repositorio.

Solo guarda preferencias y marcadores en el almacenamiento local del navegador; no guarda una copia de las páginas. Para retomar, vuelve a seleccionar el mismo capítulo. No sincroniza biblioteca ni progreso entre dispositivos. Se necesita Internet para cargar la web.

No traduce: muestra las páginas ya preparadas.

## Dependencias

Incluye zip.js con su licencia en `vendor/LICENSE-zip.js.txt`.
